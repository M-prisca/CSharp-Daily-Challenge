# C# Daily Challenges

A collection of daily C# coding challenges to strengthen my programming skills, improve problem-solving abilities, and prepare for technical interviews.

## Goals

- Practise writing clean, simple, and maintainable C# code.
- Improve problem-solving and logical thinking.
- Strengthen C# fundamentals and intermediate concepts.
- Explore different approaches to solving programming problems.
- Practise writing and running unit tests with xUnit.
- Build consistency through daily coding practice.

## Tech Stack

- **Language:** C#
- **Framework:** .NET 10
- **Testing:** xUnit
- **Version Control:** Git & GitHub
